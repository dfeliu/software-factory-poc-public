# fastapi-service

Minimal FastAPI service template for the `fastapi-service` Golden Path.

## Local use

```bash
cp .env.example .env
uv sync --locked --all-groups
uv run uvicorn application.main:app --reload
```

`GET /health` is a liveness endpoint; it does not check PostgreSQL.

For Docker Compose:

```bash
cp .env.example .env
docker compose up -d db
docker compose run --rm migrate
docker compose up -d app
```

The example values are local placeholders. Do not commit `.env` or put a real
secret in it.

## Configuration

For local Compose, `POSTGRES_DB`, `POSTGRES_USER`, and `POSTGRES_PASSWORD` are
the base database values. The application builds its URL from them. In another
environment, injected `DATABASE_URL` takes precedence.

## Validation

```bash
uv lock --check
uv run --locked ruff check .
uv run --locked ruff format --check .
uv run --locked pytest -m "not integration"
docker compose --profile test up --build --abort-on-container-exit --exit-code-from test test
docker compose --profile test down --volumes --remove-orphans
```

## CI

`.forgejo/workflows/` is the provider adapter location required by the Golden
Path. A generated project must populate it with the Forgejo Actions workflow
that invokes the shared Factory Core validation contract.

## Migrations

```bash
uv run --locked alembic heads
uv run --locked alembic upgrade head
uv run --locked alembic revision --autogenerate -m "describe change"
```

Review autogenerated revisions. Migrations never run during application startup.
