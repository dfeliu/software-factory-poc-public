# Estàndard de codi

## Finalitat

Aquest estàndard defineix les expectatives bàsiques de qualitat del codi per als projectes produïts per la factory.

## Requisits mínims

- Escriure codi llegible i mantenible, amb noms i límits que expressin la intenció.
- Mantenir explícites les dependències i evitar-ne les innecessàries.
- Tractar deliberadament els errors esperats i conservar context útil de diagnòstic sense exposar dades sensibles.
- Utilitzar els mecanismes de tipus i validació adequats del llenguatge quan millorin la fiabilitat.
- Mantenir secrets, credencials i valors específics d'un entorn fora del codi font.
- Aplicar el formatador i el linter configurats al projecte abans de preparar un canvi.

## Fora d'abast

Aquest estàndard no selecciona una versió del llenguatge, un formatador, una configuració de linter, una estructura de directoris ni convencions específiques d'un framework.
