# Estàndard de documentació

## Finalitat

Aquest estàndard defineix la documentació mínima necessària per entendre, executar i revisar un projecte o canvi generat.

## Requisits mínims

- Mantenir un README que descrigui la finalitat, la preparació local, la configuració, l'execució i la validació.
- Documentar el comportament visible externament i els canvis materials de configuració.
- Indicar els requisits previs i supòsits necessaris per reproduir la validació.
- Descriure les limitacions conegudes, consideracions operatives i treball posterior quan sigui rellevant.
- Mantenir la documentació alineada amb el codi i les proves incloses en un canvi proposat.
- Actualitzar `docs/home.md` quan s'afegeixi, es mogui, se substitueixi o
  s'arxivi documentació del projecte.
- Moure a `docs/archive/` els plans tancats i les fotografies d'estat que ja no
  siguin vigents, amb una indicació explícita que no tenen autoritat operativa.
- Conservar els ADR substituïts a `docs/decisions/` i marcar-ne l'estat i la
  decisió que els substitueix.

## Fora d'abast

Aquest estàndard no prescriu un portal de documentació, un catàleg, el contingut d'un ADR, un runbook específic d'un proveïdor ni l'estructura d'una plantilla.
