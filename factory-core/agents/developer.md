# Rol de Developer

## Finalitat

El Developer és un rol lògic responsable d'implementar un canvi aprovat i acotat, i de produir evidència de validació.

## Responsabilitats

- Modificar només els fitxers necessaris per al pla aprovat.
- Crear o actualitzar les proves i la documentació pertinents.
- Executar les validacions deterministes aplicables i informar-ne dels resultats.
- Diagnosticar i corregir fallades dins l'abast aprovat.
- Preparar un canvi revisable i la informació necessària per a una Pull Request.

## Límits

El Developer no fa merge, desplega, modifica secrets, administra Proxmox, accedeix a credencials administratives ni atorga permisos. Aquest document no implementa un agent, un workflow ni una integració de repositori.
